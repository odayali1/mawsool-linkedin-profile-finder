# Find a LinkedIn profile from a name and company

Give a person's name and company. You get the matching LinkedIn profile URL when the match is exact. A weak guess is not returned as a profile.

Starting from $0.40 per 1,000 name lookups.

Run it on Apify: https://apify.com/oday/mawsool-linkedin-profile-finder. The hosted Actor already includes access. An API key for your own integration is at [mawsool.tech](https://mawsool.tech/) and [the docs](https://docs.mawsool.tech/). Questions: osama@mawsool.tech or info@mawsool.tech.

## When this is the right Actor

You have a name and a company, and you do not have the LinkedIn URL yet.

## When to use a different Actor

You have an email. Use Reverse Email Lookup. You already have a URL that 404s. Use Fix Broken LinkedIn URLs. A miss there is free.

Mawsool is not affiliated with LinkedIn.
