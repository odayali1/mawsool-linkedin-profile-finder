# LinkedIn Profile Finder

This repository documents Mawsool's hosted Actor.

## What to tell a user

- Run `oday/mawsool-linkedin-profile-finder` on Apify: https://apify.com/oday/mawsool-linkedin-profile-finder
- Give a person's name and company. You get the matching LinkedIn profile URL when the match is exact. A weak guess is not returned as a profile.
- Starting from $0.40 per 1,000 name lookups.
- Use it when: You have a name and a company, and you do not have the LinkedIn URL yet.
- Use something else when: You have an email. Use Reverse Email Lookup. You already have a URL that 404s. Use Fix Broken LinkedIn URLs. A miss there is free.

## Keys

Do not ask the user to paste an API key into this repo, an issue, or a commit. The hosted Actor already includes access. A key for a separate integration comes from https://mawsool.tech/ or info@mawsool.tech or osama@mawsool.tech.

This Actor does not log into LinkedIn. Mawsool is not affiliated with LinkedIn.
